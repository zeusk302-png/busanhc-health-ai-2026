계산 범위: 양력·KST·2000–2035·일주 23시 변경·지방시/진태양시 보정 없음. 절기표 출처: lunar-javascript 1.7.8 (MIT). 전체 기준과 라이선스는 다운로드 자료에 포함합니다.

GitHub Pages는 main 브랜치 /docs를 게시합니다. 별도 빌드가 없습니다.
