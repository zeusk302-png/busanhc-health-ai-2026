부산보건고 · 내 사주·오행 카드 서비스 시작 키트

1. ZIP을 우클릭 → 모두 압축 풀기. ZIP 안에서 바로 열지 않습니다.
2. 풀린 폴더의 index.html을 더블클릭합니다. 처음부터 작동하는 공통 시작 화면입니다.
3. 가상 예시 넣기 → 카드 계산하기를 눌러 년·월·일·시가 乙酉 / 戊子 / 辛巳 / 壬辰인지 확인합니다.
4. AI 새 채팅에 02-AI제작자료.txt 하나를 첨부하고 03-첫요청문.txt를 붙입니다.
   [내 서비스 이름]과 [원하는 색과 느낌] 두 곳을 바꿉니다.
5. AI가 준 HTML 코드만 복사 → 메모장 → 다른 이름으로 저장.
   파일 형식: 모든 파일 / 파일명: index.html / 인코딩: UTF-8.
   확장자가 index.html.txt가 되지 않았는지 확인합니다.
6. 시작 폴더의 index.html만 바꿉니다. saju-core.js, saju-ui.js는 같은 폴더에 둡니다.
7. 저장한 index.html을 닫았다 다시 열고 가상 예시 3개, 초기화, 잘못된 입력을 시험합니다.
8. 문제가 있으면 관찰한 현상 한 개와 원래 index.html을 AI에 보내 한 번 수정합니다.
   무료 사용량이 막히면 공통 index.html에서 제목·색·설명부터 직접 바꾸고 완성합니다.
9. 제출할 때는 폴더 전체를 ZIP으로 압축해 강사가 안내한 방법으로 전달합니다.
   index.html만 보내면 계산 파일이 없어 작동하지 않습니다.

독립 예시: 한파일-완성예시.html은 계산과 화면 코드를 모두 포함합니다.
이 파일 하나만 더블클릭하면 인터넷 없이 예시가 동작합니다. AI에 첨부할 필요는 없습니다.
학생이 바꾼 index.html은 3개 파일 구조이므로 폴더 전체를 보관해야 합니다.

과제: 내 이름의 서비스 한 개 / 가상 예시 3개 계산 확인 / 수정 전후 한 가지 / 실제 파일 전달.
실명·실제 생년월일·계정 화면을 제출하지 않습니다.
