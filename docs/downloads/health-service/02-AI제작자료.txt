AI 제작자료 — 사주·타로 건강정보 챗봇

[만들 것]
생년월일 입력 → 사주·오행 카드 → 타로 카드 한 장 선택 → 음식 후보·영양정보 → 문답을 한 웹페이지에서 이용합니다.
사주 계산·카드 그림·음식 데이터·문답 로직은 시작 키트에 준비되어 있습니다.
AI는 화면의 입력창, 카드 배치, 결과표, 대화창을 만들어 줍니다. 로직과 수치는 다시 추측하지 않습니다.

[같은 폴더에 이미 있는 파일]
saju-core.js: 사주 계산. 양력·KST·2000–2035년·일주 23시 변경 기준.
health-card-data.js: 사주 카드 5개, 타로 4개, 음식 6개, 식약처 100g 영양정보와 출처.
health-card-core.js: 사주 요약·카드 섞기·음식 제외·영양 계산·자료 기반 문답.
saju-ui.js: 아래 id를 찾아 입력과 결과를 연결하는 코드.
assets/: element-wood, element-fire, element-earth, element-metal, element-water,
         tarot-meal, tarot-rest, tarot-move, tarot-water,
         food-banana, food-apple, food-tofu, food-egg, food-milk, food-rice (모두 .webp).
이미지나 긴 계산표를 AI에 첨부할 필요는 없습니다. 모든 파일은 로컬에서 읽습니다.

[정보 표시]
카드 운세는 재미용, 건강·질병·영양 결핍 판단이 아님을 짧게 표시합니다.
음식 후보는 종류·제외 설정에서 고르며, 영양정보는 식약처 자료의 100g 기준입니다.
실제 섭취 전 제품의 원재료·알레르기 표시를 확인하도록 한 줄 안내합니다.
이 문답은 준비된 자료를 조회하며, 자유생성 AI가 연결된 것처럼 설명하지 않습니다.
카드와 음식 그림은 AI로 만든 예시 이미지임을 표시합니다.
페이지 제목은 기능을 설명하는 말로 쓰고, 구호·장식용 영어·과장된 강조문을 붙이지 않습니다.

[확인할 예시]
2005-12-23 08:37 KST → 乙酉 / 戊子 / 辛巳 / 壬辰 → 금 카드.
타로 카드 한 장 선택 → 음식 후보 표시 → 제외 설정이 반영되어야 합니다.
문답: 두부 단백질은? → 100g당 9.62g. 우유 200g 칼슘은? → 236mg와 출처.
자료 밖 질문은 모른다고 안내합니다. 개인 진단·약·치료를 지어내지 않습니다.

[출력]
설치 없이 시작 폴더에서 실행할 수 있는 완전한 index.html을 HTML 코드 블록 하나로 출력합니다.
계산 코드·그림·음식 자료를 다시 출력하지 않습니다.
