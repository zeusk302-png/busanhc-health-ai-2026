AI에 첨부할 제작 자료 — 이 파일 하나만 첨부합니다.

목표: 제공된 계산 엔진을 사용하는 작은 사주·오행 카드 서비스의 index.html 화면을 만듭니다.
자료의 길이를 줄이기 위해 긴 절입 표와 계산 코드는 이 첨부파일에 넣지 않았습니다.
실행에 필요한 계산 파일은 시작 키트에 이미 들어 있습니다. AI에게 계산을 다시 만들게 하지 않습니다.

[계산 기준]
양력 / KST / 2000~2035년 / 입춘·절입 시각으로 년·월주 변경 / 일주 23시 변경.
오행은 네 기둥의 겉글자 여덟 개만 셉니다. 건강·성격·미래 판단을 제공하지 않습니다.
화면은 일간 오행의 분류 설명을 표시합니다. 전체 계산규칙은 함께 받은 01-계산규칙.txt입니다.

[파일 구성]
index.html: AI와 바꿀 화면. CSS는 HTML 안의 style에 작성합니다.
saju-core.js: 계산 엔진. 이미 제공되며 수정·복제·재작성하지 않습니다.
saju-ui.js: 입력 검사와 결과 표시. 이미 제공되며 수정하지 않습니다.
세 파일을 같은 폴더에 둡니다. CDN·웹폰트·외부 이미지·라이브러리 설치 없이 실행합니다.

[반드시 유지할 연결]
head: <script src="saju-core.js" defer></script> 다음에 <script src="saju-ui.js" defer></script>
form id="saju-form"; date input id="birth-date"; time input id="birth-time".
date는 min="2000-01-01", max="2035-12-31", required; time도 required.
submit button; type="button" id="sample-button"; type="reset" button.
오류 p id="error" role="alert".
결과 section id="result" hidden. 안에 id="result-date", id="pillars", id="elements", id="story-title", id="story-text".
결과 안에 type="button" id="print-button".
위 id는 각각 하나씩 있어야 합니다. display CSS를 바꿔도 hidden 속성은 지켜야 합니다.
결과 스타일: .pillars .pillar .hanja .elements .element. 실제 값은 saju-ui.js가 넣습니다.
인라인 이벤트, 별도 계산 함수, fetch, API 호출, 폼 제출, localStorage, 개인정보 전송을 추가하지 않습니다.
접근성: 입력마다 label 연결, 키보드 초점 표시, 모바일 가로 넘침 방지, 읽기 쉬운 대비.

[이번에 바꿀 범위]
서비스 제목·색·배치·버튼 문구·설명 표현을 바꿉니다. 계산과 결과 표시 계약은 유지합니다.
제목은 기능 이름으로 쓰고, 구호·감성 문구·영어 장식 문구를 넣지 않습니다.
한 개의 완성된 index.html을 HTML 코드 블록 하나로 출력합니다. 중간을 생략하지 않습니다.
